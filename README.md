# Nandhini R — Premium Portfolio

A deployment-ready personal portfolio built using **only HTML, CSS and vanilla JavaScript**.

## Run

No installation or build step is required. Open `index.html` directly in a browser.

For local development, any static server can be used.

## Edit content

- `index.html` — portfolio content and structure
- `style.css` — visual design, responsive layouts and animations
- `script.js` — interactions, modals, counters and form validation

## Included assets

- `assets/nandhini-photo.jpg`
- `Nandhini-R-Resume.pdf`
- Internship certificates used in the Experience section
- Only the requested NPTEL and GenAI certificates are displayed in the Certifications section
